# 한국 산불 진압시간 예측

> 화재·기상·산림 데이터를 결합해 산불 진압 소요시간을 예측하고 실제 단위의 오차를 분석한 팀 프로젝트입니다.

- 형태: 팀 프로젝트
- 역할: 팀 리더
- 담당 범위: 데이터 분석 방법론 설계, 전체 모델 코드 구현·실행, 성능 비교와 최종 결과 분석
- 기술: Python, pandas, scikit-learn, statsmodels, Random Forest, LightGBM, XGBoost
- 원본 저장소: [KR-WIldfireData-MachineLearning](https://github.com/SNU-Bigdata-Fintech-AI/KR-WIldfireData-MachineLearning)

## 문제와 목표

산불 진압시간은 긴 꼬리를 가진 분포와 극단치의 영향을 크게 받습니다. 로그 스케일에서 좋은 성능을 보이는 모델도 실제 분 단위로 역변환하면 현장 활용에 충분하지 않을 수 있어 두 관점을 함께 평가해야 했습니다.

## 직접 기여

- 팀 리더로서 분석 목표, 데이터 결합 방식, 목표변수 변환과 모델 평가 기준을 설계했습니다.
- 2019–2023년 화재 데이터에 ERA5-Land 기상 데이터와 산림 통계를 결합하는 분석 흐름을 주도했습니다.
- OLS, Ridge, Lasso, Random Forest, LightGBM, XGBoost 모델 코드를 모두 구현·실행하고 같은 분할과 지표로 비교했습니다.
- 로그 단위 성능과 원래 분 단위 성능을 함께 분석해 모델의 실제 활용 한계를 정리했습니다.

## 핵심 기술 결정

진압시간의 긴 오른쪽 꼬리와 극단치 영향을 줄이기 위해 목표변수를 로그 변환했지만, 모델 평가는 로그 스케일에서 끝내지 않았습니다. 예측값을 다시 분 단위로 해석해 통계적 성능과 실제 활용 가능성을 함께 비교했습니다.

식별자와 피해 결과, 완전진화 시점처럼 예측 당시 알 수 없거나 결과를 직접 반영하는 변수는 제외했습니다. 복잡한 모델의 점수가 근소하게 좋아지는지보다 데이터 누수 없이 반복 가능한 기준선을 만드는 데 초점을 맞췄습니다.

## 결과와 검증

아래 수치는 팀 프로젝트 전체 실험 결과이며, 저는 팀 리더로서 분석 방법론과 전체 모델 구현·실행, 성능 비교와 최종 결과 분석을 담당했습니다.

- 학습 약 2,846건과 테스트 약 712건으로 실험했습니다.
- 대표 결과는 로그 RMSE 약 0.92, 로그 MAE 약 0.70이었습니다.
- 원 단위에서는 RMSE 약 320분, MAE 약 108분으로 오차가 크게 나타났습니다.
- 모델별 차이보다 극단치와 제한된 데이터가 성능의 주요 제약임을 확인했습니다.

## 제약과 개선 방향

평균적인 경향을 설명할 수 있었지만 개별 산불의 정밀한 진압시간 예측에는 한계가 있었습니다. 모델 복잡도를 높이는 것보다 더 넓은 지역·시간 데이터와 극단 사례를 설명할 수 있는 변수를 확보하는 것이 우선이라는 결론을 얻었습니다.
