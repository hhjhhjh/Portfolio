# COVID-19 환자 사망위험 예측

> 불균형 의료 데이터에서 모델 구조, 리샘플링과 분류 임계값이 사망위험 예측에 미치는 영향을 비교한 개인 프로젝트입니다.

- 형태: 통계데이터사이언스 개인 프로젝트
- 담당 범위: 데이터 전처리, 실험 설계, 모델링, 평가와 결과 해석
- 기술: Python, pandas, scikit-learn, LightGBM, Logistic Regression, Imbalanced Classification
- 원본 저장소: [COVID-19-Machine-Learning](https://github.com/hhjhhjh/COVID-19-Machine-Learning)

## 문제와 목표

기존 분석은 코로나 확진 여부를 포함해 성능이 과대평가될 가능성이 있었고, 로지스틱 회귀와 언더샘플링만 비교했습니다. 의료 데이터에서는 단순 정확도보다 사망자를 얼마나 놓치는지와 불필요한 경고를 얼마나 만드는지가 중요합니다.

## 직접 기여

- 멕시코 보건부 환자 데이터 1,048,575건과 그중 확진자 391,979건을 분석했습니다.
- 전체 환자와 코로나 확진자만 포함한 코호트를 분리해 데이터 구성을 비교했습니다.
- 분석 시점 이후에 결정되는 ICU·삽관 변수를 제외해 누수 가능성을 줄였습니다.
- Logistic Regression과 LightGBM을 비교하고 언더샘플링과 오버샘플링의 효과를 평가했습니다.
- 고정 임계값 0.5와 검증 데이터 기반 최적 임계값을 ROC-AUC, PR-AUC, precision, recall, F1-score와 혼동행렬로 비교했습니다.

## 기술적 판단

Accuracy만으로 불균형 분류 모델을 선택하지 않고 ROC-AUC와 PR-AUC, precision, recall과 F1을 함께 평가했습니다. 모델의 순위 성능과 실제 분류 결정을 분리하기 위해 학습 후 검증 데이터에서 임계값을 탐색하고, 최종 테스트 데이터에는 선택된 임계값을 적용했습니다.

사망일은 타깃 생성에만 사용하고 입력에서는 제거했으며, 삽관·ICU처럼 예측 시점 이후에 결정될 가능성이 있는 변수도 제외했습니다. 높은 점수보다 실제 사용 시점에 알 수 있는 정보로 평가하는 것을 우선했습니다.

## 실험 결과

- LightGBM은 전체 환자 테스트에서 ROC-AUC 0.9332와 PR-AUC 0.5610을 기록했습니다.
- 리샘플링에 따른 변화는 제한적이었고, 임계값 조정이 precision과 F1-score에 더 큰 영향을 줬습니다.
- 임계값을 0.50에서 0.825로 높여 precision을 0.3095에서 0.4882로, F1을 0.4583에서 0.5598로 개선했습니다.
- 같은 조정에서 recall은 0.8824에서 0.6560으로 감소해 false positive와 false negative 사이의 정책적 trade-off를 확인했습니다.

## 한계와 배운 점

임계값 최적화는 하나의 정답을 찾는 과정이 아니라 서비스 목적에 맞춰 오류 비용을 선택하는 과정입니다. 실제 의료 환경에서는 사망자를 놓치지 않는 recall과 불필요한 경고를 줄이는 precision 가운데 무엇을 우선할지 임상적 기준이 필요합니다.
