# 안저영상과 임상정보를 활용한 심혈관 질환 분류

> 좌·우 안저영상과 나이·성별 임상정보를 결합해 심혈관 질환을 예측한 멀티모달·멀티태스크 딥러닝 연구입니다.

- 형태: 개인 연구 프로젝트
- 기간: 2025년 3월–6월
- 담당 범위: 문제 정의, 데이터 전처리, 모델 설계, 실험, 결과 분석, 논문 작성
- 성과: 제1저자, 대한임베디드공학회 ICT 대학생 논문경진대회 우수논문발표상 장려상(3위)
- 기술: Python, PyTorch, EfficientNetV2-S, Siamese Network, Focal Loss, Multimodal Learning, Multitask Learning
- 원본 저장소: [Multimodal-CVD-Classification](https://github.com/hhjhhjh/Multimodal-CVD-Classification)

## 문제와 목표

안저영상에는 심혈관 상태와 연관된 시각적 특징이 포함되지만, 영상만으로 설명하기 어려운 나이와 성별 같은 임상 요인도 질환 예측에 영향을 줍니다. 서로 다른 데이터 유형을 결합했을 때 단일 모달 모델보다 유용한 표현을 학습할 수 있는지 검토했습니다.

## 직접 기여

### 비교 가능한 실험 단계 설계

단일 안저영상 모델을 기준선으로 구축하고, 좌·우 영상 결합, 임상정보 결합, 분류와 회귀를 함께 학습하는 멀티태스크 구조로 실험 범위를 확장했습니다. 환자 단위로 학습·검증·테스트 데이터를 나눠 동일 환자의 영상이 서로 다른 데이터 분할에 섞이는 것을 방지했습니다.

### 멀티모달 모델 구현

EfficientNetV2-S로 좌·우 안저영상 특징을 추출하고, 2-layer MLP로 임상정보를 표현한 뒤 중간 특징을 결합했습니다. 분류에는 Focal Loss를 사용하고, 멀티태스크 실험에서는 회귀 손실을 함께 적용했습니다.

### 반복 실험과 구조 비교

학습률, 손실 가중치, 이미지 인코더, 임상정보와 회귀 헤드의 포함 여부를 바꾼 실험을 수행했습니다. 단순히 최종 모델 하나만 남기지 않고 단일 모달과 여러 멀티모달 구조를 비교할 수 있도록 실험 기록을 보존했습니다.

## 기술적 판단

좌·우 영상은 같은 종류의 입력이므로 가중치를 공유하는 Siamese 구조로 특징을 추출했습니다. 질환 분류를 주 태스크로 두고 CIMT 연속값 회귀를 보조 태스크로 추가해, 분류 경계와 관련된 생리적 정보를 함께 학습하도록 설계했습니다.

이미지 단위 무작위 분할은 같은 환자의 양안 영상이 서로 다른 세트에 들어갈 수 있으므로 사용하지 않았습니다. 환자 단위 분할을 적용해 평가 데이터 누수를 방지했습니다.

## 구현 및 연구 산출물

- 총 2,903명의 환자 데이터를 환자 단위로 분할해 학습했습니다.
- 좌·우 안저영상, 임상정보, 보조 회귀 목표를 함께 다루는 모델 구조를 구현했습니다.
- 이미지 단독 기준선부터 멀티모달·멀티태스크 모델까지 일관된 학습 흐름에서 비교했습니다.
- 최종 MM-C-R 모델은 정확도 83.67%, AUC 0.926, precision 0.853, sensitivity 0.837, F1 0.837을 기록했습니다.
- 최고 성능의 단안 기준선보다 정확도 8.0%p와 F1 0.084를 개선했습니다.
- 연구 결과를 제1저자 논문과 발표 자료로 정리해 2025년 6월 30일 우수논문발표상 장려상(3위)을 받았습니다.

## 한계와 배운 점

- 제한된 단일 데이터셋 결과이므로 외부 의료기관 데이터에 대한 일반화 검증이 필요합니다.
- 멀티태스크 손실 가중치와 임상 변수 범위가 결과에 미치는 영향을 더 체계적으로 분리할 필요가 있습니다.
- 의료 AI에서는 무작위 이미지 분할보다 환자 단위 분할과 데이터 누수 방지가 모델 구조만큼 중요하다는 점을 확인했습니다.
