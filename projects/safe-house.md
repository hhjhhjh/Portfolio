# 안전한 자취방 구하기

> 서울시 공공데이터와 부동산 매물 정보를 결합해 동과 실제 오피스텔 매물 단위의 안전도를 시각화한 프로젝트입니다.

- 기간: 2024년 11월 9일–2025년 1월 25일
- 형태: 4인 팀 프로젝트
- 담당 범위: 동별 안전도 군집화, 오피스텔 주변 변수 결합, 매물별 안전점수 산출
- 기술: Python, pandas, scikit-learn, GeoPandas, K-means, PCA, Folium, Kakao Local API
- 원본 저장소: [safe-house](https://github.com/Tave-14-Aespo/safe-house)

## 문제와 목표

공개된 안전 지표는 주로 구 단위로 제공되어 실제 자취방 주변 환경을 비교하기에는 해상도가 낮습니다. 프로젝트는 법정동 단위 안전도와 개별 매물 주변의 생활·안전 시설을 함께 보여주는 것을 목표로 했습니다.

## 직접 기여

- 지하철역, 범죄 건수, 치안시설, 등록인구 데이터를 결합해 동별 특성을 구성했습니다.
- 여러 군집화 결과를 비교하고 동별 안전 그룹을 산출했습니다.
- 오피스텔 주소와 반경 300m·500m 내 버스정류장 정보를 결합했습니다.
- 서울 오피스텔 3,781건을 지오코딩하고 주변 CCTV, 가로등, 학교, 버스정류장 변수를 이용해 실제 매물별 안전점수를 계산했습니다.

## 팀의 기술적 접근

팀은 서로 다른 공간 단위의 데이터를 법정동과 좌표 기준으로 정렬한 뒤, 동 수준의 군집 결과와 매물 반경 내 시설 정보를 분리해 계산했습니다. 최종 결과에서는 실루엣 점수를 기준으로 K-means 군집 수를 정하고 PCA 투영과 변수 로딩값으로 군집을 해석했습니다. 제 직접 담당 범위는 군집화 대안 비교와 동별 그룹 산출, 오피스텔 데이터 전처리와 매물별 안전점수 계산입니다.

안전점수는 범죄 발생 확률이 아니라 제한된 공개 지표를 결합한 상대적 비교값으로 정의했습니다. 점수의 의미가 실제 위험 보장으로 확대 해석되지 않도록 한계를 함께 명시했습니다.

## 팀 결과

아래 내용은 팀 프로젝트 전체 결과이며, 제 직접 담당 범위는 동별 안전도 군집화, 오피스텔 주변 변수 결합, 매물별 안전점수 산출입니다.

- 서울시 법정동별 상대적 안전도를 지도에 시각화했습니다.
- 개별 오피스텔 매물에 50–100점 범위의 안전점수를 부여했습니다.
- 주소 검색을 통해 매물 주변 안전 정보를 확인하는 결과 화면을 구현했습니다.

## 한계와 배운 점

군집과 회귀 점수는 상대적 비교 지표이며 실제 범죄 위험 확률이나 거주 안전을 보장하지 않습니다. 공공데이터의 집계 단위와 갱신 시점, 시설 개수와 실제 안전 사이의 인과관계를 구분해 설명해야 한다는 점을 배웠습니다.
