# 피그널: 피부 트러블 위치 분석 서비스

> 얼굴 이미지에서 피부 트러블을 탐지하고 얼굴 부위별 정보를 제공하는 컴퓨터 비전 웹 서비스입니다.

- 기간: 2025년 2월 19일–3월 18일
- 형태: 5인 팀 프로젝트
- 담당 범위: 데이터 전처리, YOLOv8 모델 학습·모델링과 추론 후처리, Flask 백엔드, DB와 사용자 화면 연결
- 기술: Python, TensorFlow, KerasCV, YOLOv8, OpenCV, MediaPipe, Flask, SQLAlchemy, SQLite
- 원본 저장소: [acne-CV](https://github.com/NIS-co-create/acne-CV)

## 문제와 목표

이미지에서 피부 트러블을 탐지하는 것만으로는 사용자에게 의미 있는 결과를 제공하기 어렵습니다. 탐지된 위치를 얼굴의 이마, 코, 양 볼, 턱 영역과 연결하고 결과를 웹 화면에서 확인할 수 있어야 했습니다.

## 서비스 흐름

```mermaid
flowchart LR
    A[얼굴 이미지 업로드] --> B[MediaPipe 얼굴 영역 분할]

    D --> E[Flask API · SQLite 저장]
```

## 직접 기여

### 모델 학습과 서비스 추론 흐름 구현

Kaggle Acne Dataset을 YOLO 학습 형식으로 전처리하고 KerasCV 기반 YOLOv8 모델을 학습했습니다. 학습 가중치를 웹 서비스의 추론 파이프라인에 연결하고, 얼굴 영역별 이미지를 640×640 크기로 변환해 추론했습니다. Confidence threshold 0.4를 적용한 뒤 탐지 좌표를 원본 이미지 좌표계로 복원했습니다.

### 탐지 결과와 얼굴 영역 결합

YOLO 기반 트러블 탐지 결과와 MediaPipe Face Mesh의 468개 랜드마크를 결합하고, 이마·코·왼쪽 볼·오른쪽 볼·턱의 다섯 영역별 판정과 점수 계산 흐름을 구현했습니다.

### 웹 애플리케이션 구현

Flask 애플리케이션에서 이미지 업로드, 모델 추론, 결과 저장, 상세 결과와 기록 조회가 이어지도록 서버와 템플릿을 구현했습니다. 프로젝트 후반에는 최종 서버 코드를 통합했습니다.

## 핵심 기술 결정

모델 결과를 그대로 보여주지 않고 얼굴 랜드마크를 기준으로 영역을 나눈 뒤 탐지 좌표를 다시 매핑했습니다. 모델 추론, 후처리, 결과 해석과 저장을 분리해 각 단계의 좌표 변환과 예외를 확인할 수 있도록 구성했습니다.

서비스는 의료 진단이 아닌 참고용 건강관리 정보 제공으로 범위를 제한했습니다. 검증되지 않은 인과관계를 질환 판정처럼 표현하지 않는 것이 모델 정확도만큼 중요하다고 판단했습니다.

## 프로토타입 결과

아래 내용은 팀이 구현한 프로토타입의 결과이며, 제 직접 담당 범위는 데이터 전처리, YOLOv8 모델 학습·모델링과 추론 후처리, Flask 백엔드, 데이터 저장과 사용자 화면 연결입니다.

- 얼굴 이미지 업로드부터 트러블 위치 분석과 부위별 결과 표시까지 이어지는 프로토타입을 구현했습니다.
- 이마, 코, 왼쪽 볼, 오른쪽 볼, 턱의 다섯 영역으로 결과를 나눴습니다.
- 분석 기록을 저장하고 다시 조회할 수 있는 화면 흐름을 구성했습니다.

## 제약과 개선 방향

- 피부 상태와 신체 기관의 관계가 의료적 진단으로 오해되지 않도록 서비스 표현과 검증 범위를 엄격하게 제한해야 합니다.
- 후속 검증에서는 촬영 각도, 조명과 얼굴 정렬 조건을 나눠 탐지 성능과 실패 사례를 측정할 필요가 있습니다.
- 서비스 확장을 위해서는 추론 실패 상태, 낮은 신뢰도의 결과와 입력 품질 문제를 사용자에게 구분해 설명하는 흐름이 필요합니다.
